Combine any of them with a size modifier — .btn-lg, the unmodified default (medium), .btn-sm, or .btn-tiny — and drop an inline <svg> before or after the label for a leading or trailing icon.

Alerts

Pill-shaped status banners for surfacing success, info, warning, and error states — three visual weights (standard, filled, outlined) built on one shared icon set. Each one is a single line: no inline SVG required, just alert plus a severity (success / info / warning / error) and, optionally, fill or outline. The icon is added automatically by CSS and always matches the alert's colour.

Code Block

Just write plain <pre><code> — no wrapper <div>, no language class, no header markup. script.js finds every code block on the page, wraps it, adds a copy button, and runs it through highlight.js, which auto-detects the language and colors it using the --hl-* tokens in styles.css.

Code Block
const tools = ['lookup_order', 'issue_refund', 'escalate_to_human'];

function pickTool(intent) {
  if (intent === 'order_status') return tools[0];
  return tools[2];
}

Steps

A numbered vertical timeline — just a plain <ol> or <ul> with the .steps class (numbering is generated by CSS, so it works the same either way). A solid line connects each circle to the next, all in your theme's primary color. Each item can be a plain line of text, or richer — a bold title, a description paragraph, and a muted timestamp.
